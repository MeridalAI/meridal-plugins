# Les plugins de Meridal

Un marketplace de plugins pour assistants d'IA, publié par Meridal, cabinet de conseil et de formation à l'IA pour les PME.

| Plugin | Ce qu'il fait |
|---|---|
| `meridal-outils-ia` | Choisir entre un abonnement d'IA d'équipe et l'API d'un modèle, sur des prix relevés et datés |

```bash
claude plugin marketplace add https://github.com/MeridalAI/meridal-plugins
claude plugin install meridal-outils-ia@meridal
```

Chaque plugin dit qui le publie, cite ses sources et ne recommande aucun prestataire. Voir `plugins/meridal-outils-ia/README.md`.
